# Lady_GYM review — 5 November 2026

**Why the link said 404.** Lady_GYM was built on a branch and its pull request was never merged,
and GitHub Pages publishes only `main`. So `sal-padilla.github.io/daybreak/ladygym` and
`/daybreak/Lady_GYM/` did not exist on the live site, in Safari or anywhere else. Merging it to
`main` publishes both. Nothing about Safari caused the 404, but the review below found several
things that would have broken on an iPhone once it was live.

Four reviewers worked in parallel — iPhone Safari & deployment, hands-on use of every screen,
the new UI and database code, and the training engine ported from Daybreak — and every fix was
reproduced first and then re-checked in Chromium with iPhone screen sizes, light and dark,
large text, offline, and the clock set to California mornings and evenings. Real Safari was not
available, so Safari-only behaviour was checked against WebKit's documented support.

## Fixed

**Opening and installing it on a phone**
- Daybreak's offline worker deleted Lady_GYM's offline copy every time Daybreak updated, and the
  copy of it already on test phones saved Lady_GYM's pages as Daybreak's. Daybreak now leaves
  Lady_GYM alone, and its new cache name (v0.9.3) sweeps out anything the old worker saved.
- On a phone with Daybreak, Lady_GYM reloaded itself a few seconds into sign-up.
- Daybreak's "Get the latest version" button wiped Lady_GYM's offline copy too.
- Lady_GYM could save a stray page in its folder as its offline home screen.
- A Home Screen app opened the next morning still showed yesterday, with no Start button.

**iPhone Safari**
- Tapping the profile photo did nothing until a photo was set (the picker must open inside the tap).
- Restoring a backup could silently do nothing (a detached file input can be discarded).
- Saving a backup could fail outright if iOS refused the share sheet; it now downloads instead.
- At the two smallest iPhone text sizes, tapping a field zoomed the page and stayed zoomed.
- Picture backgrounds could vanish: the same gradient id appeared many times on the page.
- In landscape, buttons sat under the notch / Dynamic Island.
- If iOS closed the database while the app was in the background, the next set could fail to save.

**The workout**
- A double tap ran actions twice: two workouts from one "Let's Go!", a set logged twice, two
  players stacked, two measurements from one Save.
- Saturday's sprint session opened empty, and Saturday's "View Workout" showed Monday's legs.
- Holds and cardio pre-filled 30 seconds / 1 minute whatever the plan said.
- A "lighter" morning could make a weight heavier (12 lb × 0.95 came out as 12.5).
- "We drop the last set" on a rough morning did not drop it.
- Barbell lifts were offered 5–20 lb, less than the bar; increases landed on weights that do not
  exist (10.5, 14.5 lb).
- After a 15-minute bike session the next target said to add a dumbbell or a vest.
- The warm-up timer kept running after a workout was ended and skipped moves in the next one; a
  tap on Next at 0:00 skipped a move; "+15 s" on the rest timer showed the wrong time.
- Resuming a workout opened at the first exercise instead of where she left off.
- "Rest between sets" in Profile changed nothing. It now defaults to "As planned".

**Her data**
- A workout left without tapping Finish disappeared from History, the week and the rings the next day.
- Skipping a class for one week and re-adding it doubled it in every later week.
- "Clear the demo data" deleted her real progress photos and avatar.
- A crafted backup could run code when restored; stored text is now escaped everywhere it is shown.

**Showing the right thing**
- The leg-recovery warning offered moves that could never happen, and "Fix it for me" never showed.
- The weekly report blanked waist and hips after an InBody scan, and showed "95 → 95 lb (+5%)".
- "Getting stronger", the backup date and the tip of the day used the UTC date (wrong after 4 pm).
- "Best set" never updated for exercises done above 12 reps.
- "Pick a weight you could do 12 times" showed for planks and sprints; "all 1 sets"; "1 sets"; "5 × 5–5".
- The pelvic-floor question promised to swap jumps automatically. Nothing in the exercise data can
  do that safely, so the promise is gone and the true advice stays.
- At large text sizes on small phones: Save buttons pushed off-screen, the keypad's +5 key off
  the edge, Sunday cut off the week, numbers truncated ("10/10." for "10/10.5").

## Checked and fine

The load path from the short link to the Home Screen and offline; old-Daybreak-worker upgrade;
no JavaScript or CSS newer than iOS 16.4; a v1 database upgrading to v2 with its data; backup
round trips, including Daybreak backups; resume after the app is killed; the rest timer after
the phone sleeps; 306,000 simulated weeks of the engine across every life stage, experience and
class mix, both DST changes and New Year; every exercise and class id the plans reference.

## Open — decisions, not bugs

- **Deloads.** `deloadEveryWeeks` is set per life stage but nothing schedules a lighter week
  (Daybreak is the same).
- **Bar weight.** Barbell, trap-bar and Smith lifts assume a 45 lb bar, with 35 lb offered first.
  The library does not record bar weights.
- **Leaking + jumps.** A real low-impact swap needs new low-impact alternatives in the library.
- Three leg-heavy classes in one week can still put a leg day before Monday HIIT (60 of about
  19,000 class combinations), with no warning.
- "Fix it for me" moves cannot be undone; the same workout is estimated at ~65 min on Today and
  ~61 min on its own page; swapping an exercise mid-workout hides that exercise's logged sets
  until Finish (nothing is lost).
- No `navigator.storage.persist()`: in a Safari tab (not the Home Screen app) Safari can clear
  the data after seven days without a visit. The app already steers people to the Home Screen.
- At the very largest accessibility text size on a 320pt phone, the player's tick button sits
  5 px past the edge (still tappable).

## Daybreak

Daybreak shares the engine, so it had the same engine bugs. They were ported to it in
**Daybreak v0.9.4**: the heavier "lighter" morning, cardio minutes read as seconds, unreal
weights, the "pick a weight" message on planks, the impossible move suggestions, the 30-second
pre-fill and missing timed target, the dropped set that was not dropped, "5 × 5–5", the
"30 → 30 lb" report line, the InBody blanking, waist:hip to one place, recommendations and the
daily note using UTC dates, and the pelvic-floor promise. Its service worker and its "Get the
latest version" button were also changed so the two apps can share the site. Daybreak's own
screens (double taps, layout at large text) were not part of this review.

## Re-running the checks

```bash
node Lady_GYM/tools/check.mjs
```
